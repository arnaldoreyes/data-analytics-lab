# Data Analytics Lab

Bienvenido al laboratorio de entrenamiento práctico y desarrollo de soluciones analíticas. Este repositorio contiene proyectos cortos, casos de estudio y ejercicios prácticos orientados a resolver problemas de negocio en las áreas de **Business Intelligence (BI)**, **Ventas** y **Operaciones (Supply Chain e Inventario)**.

El objetivo central de este laboratorio es desarrollar y afinar criterio analítico, manipulación de datos y construcción de reportes bajo estándares reales de industria.

---

## 🛠️ Stack Tecnológico

El trabajo dentro de este laboratorio se enfoca en el trío fundamental del análisis de datos comercial y operativo:

* **SQL (PostgreSQL / MySQL):** Extracción, limpieza, filtrado avanzado, relaciones entre tablas, lógica condicional (`CASE WHEN`) y agregaciones.
* **Microsoft Excel & Google Sheets:** Modelado rápido, funciones de búsqueda (`XLOOKUP`, `INDEX/MATCH`), agregaciones condicionales (`SUMIFS`) y Tablas Dinámicas.
* **Power BI (Desktop & Public):** Transformación de datos con Power Query, modelado dimensional (Modelo en Estrella), métricas en DAX y diseño de dashboards ejecutivos.
